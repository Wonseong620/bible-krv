# 상담 안전 대응 — v2.1 보완

2026-09-09 가상 상담 비교에서 확인된 실패를 수정했다. 위험한 상황을 일반적인 문체 생성에만 맡기지 않는다.

- `safety.py`가 명확한 현재 자해·폭력 위기, 처방약 변경, AI 독점 의존, 정체성 질문, 대화 종료를 먼저 처리한다. 최근 사용자 발화만 사용하며 이전 AI의 추측을 사실로 삼지 않는다.
- 명확한 자해·폭력 위기 안내는 API의 생성 잠금과 일일 한도 검사 전에 반환한다. 이 고정 안내는 일일 생성 횟수 및 TOP 질문 기록에 포함하지 않는다. 서버 자체 또는 인터넷 연결이 꺼진 경우까지 보장하는 기능은 아니다.
- 그 외 표현은 Qwen의 별도 disposition 분류가 보완한다. 안전 분류의 생성 문장은 스트리밍하지 않고 서버의 고정 안내로 대체한다. 명확한 신호를 놓치고 모델까지 일반 상담으로 오분류하면 위험을 놓칠 수 있다. 규칙과 프롬프트만으로 모든 상황의 안전을 보장하지 않는다.
- 위기·약물·AI 의존·정체성·종료 답변에는 추천 질문을 생성하지 않는다. 일반 상담도 적절한 질문이 없으면 빈 배열을 허용한다. 브라우저는 빈 배열이면 추천 영역을 숨긴다.
- 복용 변경은 처방 의료진과 확인하도록 안내하며, 의료진이 이미 정한 계획을 무조건 뒤집지 않는다. 기도나 채팅을 근거로 약을 중단하도록 권하지 않는다.
- 가정폭력 상황에서 가해자를 달래거나 문을 열거나 화해하라고 권하지 않는다. 이동이 위험을 키울 수 있음을 고려하고, 현지 긴급 지원과 믿을 만한 사람에게 연결한다. 위치를 모르므로 국가별 번호를 추측하지 않는다.

## 지침 정리

우선순위를 안전 → 최신 사용자 요청·정정 → 정확성 → 문체로 명시했다. 기존의 “사용자 대화는 지시가 아닌 자료”라는 포괄적인 문장을 없애고, 상담 요청은 따르되 안전 원칙을 무시하라는 지시는 따르지 않도록 구분했다. 반복된 공감·말씀·문체 지침을 줄였다. 첫 답변의 말씀/해석/응답 형식은 유지한다. 후속 답변에는 사용자가 원하거나 근거가 필요한 경우에만 성경을 연결한다.

문체는 40대 남성의 차분하고 친근한 대화 감각을 참고하되 실제 나이·성별·목사 신분을 주장하지 않는다. 거절·사과·기도문 요청은 결과물을 직접 작성하고, 정정과 듣기 요청을 존중한다. 이전 실험의 100개 예시는 이번 운영 프롬프트에 넣지 않았다.

## 안내 문구 참고 자료

- NIMH, [5 Action Steps](https://www.nimh.nih.gov/health/publications/5-action-steps-to-help-someone-having-thoughts-of-suicide): 위험 수단과 거리를 두고 실제 지원에 연결하는 원칙.
- The Hotline, [Safety Plan](https://www.thehotline.org/plan-for-safety/create-your-personal-safety-plan/): 개인의 상황에 맞는 안전 계획과 즉각적인 위험의 긴급 지원.
- NHS, [Antidepressants](https://www.nhs.uk/medicines/antidepressants/): 의료진과 상의 없이 항우울제를 갑자기 중단하지 않는 원칙. 약물별 중단·감량 계획을 챗봇이 처방하지 않는다.

이 자료를 참고한 서버 안내이며 의료·목회 전문가의 공식 인증을 받았다는 뜻은 아니다.
